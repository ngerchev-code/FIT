# FIT — Fitness AI Coach: състояние на изпълнението

Задание: `docs/CLAUDE_IMPLEMENTATION_BRIEF.md` (версия 2026-11-02). Референтната логика е в `docs/workout_core.reference.ts`, а работещият порт е в `www/fit-core.js`.

## Архитектура (одит, 2026-11-03)

| Част | Файл / място | Бележка |
|---|---|---|
| Приложение (UI + логика) | `www/index.html` (≈2000 реда, един файл) | Ванилов JS, без framework. Модулите се добавят чрез `tools/extraN.js` → `tools/patch_*.py` |
| Ядро на тренировката (ново) | `www/fit-core.js` | Чиста логика без зависимости: state machine, идемпотентност, планиране, пропусната тренировка |
| Android обвивка | `android/` (Capacitor 7), `capacitor.config.json` | Подписан APK/AAB от `.github/workflows/android.yml` |
| Обновяване по въздуха | `@capgo/capacitor-updater`, `web.zip` в Releases | Web промени → без нова инсталация; `android/NATIVE_VERSION` = 11 |
| Данни | `localStorage["fit_app_v1"]` (обект `S`) | Само на устройството; няма сървър и акаунт |
| AI | `server/netlify/functions/scan.mjs` или ключ на потребителя | Снимка → уред/упражнения, чат |
| Тестове | `tools/audit.py` (Playwright, 2 режима), `tools/test_core.mjs` (ново) | |

**Рискове.** Един голям HTML файл; данните са само локално (няма синхронизация между устройства); няма iOS проект до този етап; няма часовник (Wear OS/watchOS изискват нативен код).
